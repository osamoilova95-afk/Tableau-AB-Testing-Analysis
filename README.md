## 📝 Project Overview
This project focuses on analyzing the results of an A/B test to evaluate user behavior and traffic distribution across different segments. The interactive dashboard allows stakeholders to filter and drill down into the data by various dimensions.

## 🛠️ Key Features & Insights Visualized
* **Group Distribution:** 50/50 split verification between Group 1 and Group 2 to ensure proper randomization.
* **Device Segment Analysis:** Breakdown of traffic performance across mobile, desktop, and tablet devices.
* **Acquisition Channels:** Evaluation of user distribution coming from Direct, Paid, Social, and Organic channels.
* **Geographical Distribution:** Insights into traffic by continents and specific regions.

## 🧰 Tools & Technologies Used
* **Tableau Public** — for data visualization and dashboard design.
* **Data Sources** — processed test datasets incorporating device, channel, and regional attributes.
